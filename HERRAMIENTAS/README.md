# Programas del curso

**SI-886 · Planeamiento Estratégico de TI**

Los programas de los talleres **ya no viven aquí**. Están en la carpeta `RECURSOS-TALLER/` de cada semana, junto con los documentos del banco de casos que ese taller usa, para que cada semana sea autosuficiente. Cada guía de taller enlaza directamente a su programa y el README de cada carpeta dice qué lee, qué produce y desde qué carpeta del repositorio se ejecuta.

Esta carpeta se conserva solo como índice y puede eliminarse.
