# Plantillas de entrega · SI-886 Planeamiento Estratégico de TI

Estas dos plantillas son el **formato obligatorio** para entregar los trabajos
del curso. Se llenan en Word y se entregan en **PDF**.

| Plantilla | Para qué | Cuándo se entrega |
|---|---|---|
| [SI886-PLANTILLA-DINAMICA.docx](SI886-PLANTILLA-DINAMICA.docx) | Lo que el grupo resolvió en la dinámica de aula | Antes de cerrar la sesión de teoría |
| [SI886-PLANTILLA-TALLER.docx](SI886-PLANTILLA-TALLER.docx) | El informe del taller de laboratorio, en formato EPIS | 48 horas después del taller |

## Cómo se nombra el archivo

```
SI886-S<NN>-DINAMICA-Grupo<N>.pdf      ejemplo: SI886-S03-DINAMICA-Grupo4.pdf
SI886-S<NN>-TALLER-Grupo<N>.pdf        ejemplo: SI886-S03-TALLER-Grupo4.pdf
```

`<NN>` es el número de la semana con dos dígitos y `<N>` el número del grupo.

## Reglas que aplican a toda entrega

1. **Se entrega en PDF**, nunca el `.docx`. Exporta con **Archivo → Guardar como → PDF**.
2. **La carátula va completa**, con los apellidos, nombres y códigos de todos los
   integrantes. Un trabajo sin códigos no se califica.
3. **Las tablas se entregan llenas.** Una tabla con las cabeceras y las celdas
   vacías no puntúa.
4. **Los textos van redactados, no descritos.** Si se pide el texto que verá un
   usuario, va la frase real, no una descripción de lo que diría.
5. **Toda afirmación se sostiene** en un dato, una norma citada por su código o
   una evidencia. Un adjetivo sin dato no es un hallazgo.
6. **En el informe de taller, actualiza el índice** antes de exportar. Clic
   derecho sobre el índice y luego **Actualizar campos**.
7. La primera página de instrucciones de cada plantilla **se borra antes de
   entregar**.

También quedan las versiones en Markdown
([dinámica](SI886-PLANTILLA-DINAMICA.md) ·
[taller](SI886-PLANTILLA-TALLER.md)) para leerlas desde GitHub sin
descargar nada.
