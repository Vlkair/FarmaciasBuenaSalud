# Cómo se usa esta plantilla

Este es el formato en el que se entrega **todo informe de taller de SI-886**. Se llena en Word y se entrega en **PDF**.

1. Guarda una copia con el nombre **`SI886-S<NN>-TALLER-Grupo<N>.pdf`**. Por ejemplo, `SI886-S03-TALLER-Grupo4.pdf`.
2. Completa la carátula. Escribe los integrantes con apellidos, nombres y código, uno por línea.
3. Copia el enunciado de cada sección desde el archivo `3-TALLER.md` de la semana. Las siete secciones son las del formato EPIS y van en este orden.
4. Actualiza el índice antes de exportar. Clic derecho sobre el índice y luego **Actualizar campos**.
5. Exporta con **Archivo → Guardar como → PDF**. No entregues el `.docx`.

Borra esta página antes de entregar.
